Hist 2 — Gross Value & Monthly Sales / Discounts

Paste Gross Value table

Same format as the customer count table, but values are gross values (monetary amounts) per discount band. Bin labels must match the customer count table so the two tables can be combined for the weighted average discount.

Calculation summary (per month, summed over every band):
  • Sales = Σ gross_value across all bands
  • Discounts = Sales × weighted_avg_discount% / 100
  • Weighted avg discount % = Σ (customer_count × midpoint%) / Σ customer_count
  • midpoint% = (start + end) / 2; for [30%, +∞) the midpoint is fixed at 33.3 %.
  • Both currency lines share the left axis so they are directly comparable; the percentage line uses the right axis.
  • Bands are joined on their (start, end) values, so bracket style ([ ] vs ( )) doesn’t matter.
