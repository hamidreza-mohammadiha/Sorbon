Hist 2 — Average Drop Size & Monthly Sales / Discounts

Paste band data (average drop size / basket value)

Same format as Hist 1 but the values are the average drop size (basket value) for each discount band. Bin labels must match the customer‑count table so rows can be joined. Month labels are auto‑generated the same way (Jan…Dec for 12 columns).

Calculation summary (per month, summed over every band):
  • Sales = Σ (customer_count × drop_size)
  • Discounts = Σ (customer_count × drop_size × midpoint%)
  • midpoint% = (start + end) / 2; for [30%, +∞) the midpoint is fixed at 33.3 %.
  • Bands are joined on their (start, end) values, so bracket style ([ ] vs ( )) doesn’t matter.
