Hist 2 — Average Drop Size & Monthly Sales / Discounts

Paste band data (average drop size / basket value)

Same format as Hist 1 but the values are the average drop size (basket value) for each discount band. Bin labels must match the customer count table so they can be combined. Month labels are auto‑generated the same way (Jan…Dec for 12 columns).

Monthly Sales & Discounts

Sales = Σ (customer count × drop size) across all bands, per month.
Discounts = Σ (customer count × drop size × band midpoint %) per month — midpoint of [30%, +∞) is set to 33.3%.
